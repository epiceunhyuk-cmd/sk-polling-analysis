## Korean Presidential Election Polls

This directory contains the original polls used in original EE. 

## File Organization

The PDF filenames correspond to the polls listed in the file - `analysis/original-ee/EE Voting Poll Database.xlsx`.

- **`001.pdf`–`044.pdf`**: Polls on 20th South Korean presidential election (2022).
- **`101.pdf`–`126.pdf`**: Polls on 19th South Korean presidential election (2017).

The numbering follows the order of the polls listed in the EE database. The gaps between the names' numbers is an intentional naming convention.

## Sources and Verification

All poll reports were sourced from the [National Election Survey Deliberation Commission (NESDC) repository](https://nesdc.go.kr/portal/bbs/B0000005/list.do?menuNo=200467).

To locate the original report for a poll:

1. Open `analysis/original-ee/EE Voting Poll Database.xlsx`.
2. Find the poll in the columns corresponding to the relevant presidential election.
3. Note the poll number recorded in the database.
4. Search for that number in the NESDC repository to locate the original report.

The NESDC repository can also be searched for polls associated with each presidential election. This allows readers to independently examine the source records and verify the coverage of the dataset used in the EE.
